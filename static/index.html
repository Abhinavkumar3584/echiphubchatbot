Project details

Language model Amazon Nova Lite on Amazon Bedrock
Knowledge base Text from the 7 eChipHub websites
Search Hybrid search: meaning (BGE-small) + exact words (BM25) in a local Qdrant database
Guardrails Blocks prompt injection, abuse and harmful requests; self-harm helpline; masks phone, e-mail, Aadhaar, PAN and card numbers; only eChipHub/NIELIT links in answers
Backend Python, FastAPI and uvicorn behind Nginx (HTTPS)
Chat widget One script line on any website (JavaScript, Shadow DOM); live status and word-by-word answers
Hosting AWS EC2, Ubuntu 24.04, Mumbai region
Data collection Playwright scraper and ingest script, run from the laptop when website content changes
Privacy No chats, answers or logs are stored. The open-chat count uses a random id per browser tab, kept in memory only.
